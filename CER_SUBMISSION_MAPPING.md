# Columbia Economic Review submission-material mapping

This file maps the journal's requested submission materials to this repository. The manuscript itself is submitted directly through the journal's submission form.

| CER request | Location / action |
|---|---|
| Main manuscript with title page, abstract, tables, and figures embedded | Submit the final manuscript directly to CER |
| Separate files for every main-paper graphic | `publication_assets/main_figures/` |
| Separate files for every main-paper table | `publication_assets/main_tables/` |
| Code | `analysis/`, `scripts/`, `providers/`, `tests/` |
| Data / spreadsheets / analysis items | `data/processed/`, `data/qualitative/`, `outputs/quantitative/` |
| Prompts and scenarios | `prompts/`, `scenarios/` |
| Reproducibility/integrity documentation | `docs/`, `VALIDATION_REPORT.md`, `SHA256SUMS.txt` |
| Supplementary material | `publication_assets/supplement/` |
| Supplementary figures | `publication_assets/supplementary_figures/` |
| LaTeX source | Not applicable; manuscript is maintained in Word |

The append-only raw technical-attempt log is retained privately. The public processed dataset contains the 360 retained successful evaluations, including raw response text and parsed outcomes, and is sufficient for the reported manuscript analyses.
